# IMAP-Konto auf Outlook einrichten

Diese Anleitung beschreibt die Konfiguration von **Outlook** auf einem Android-Gerät für ein IMAP-Konto auf Strato.
---

## Voraussetzungen

- Android Gerät mit installiertem Google Play Store
- Zugangsdaten für das IMAP-Konto
- IMAP Server: imap.strato.de
---

## Öffnen der Outlook App

- App öffen
- Tippe auf „Konto hinzufügen“
- Tippe auf „Überspringen“
- Mailadresse eingeben `wf-musterstadt@musterstadt.de`
- Kontotyp auswählen: IMAP
- Erweiterte Einstellungen anzeigen lassen
- Optional: Anzeigename eingeben
- Optional: Beschreibung für das Konto eingeben
- IMAP-Hostname: `imap.strato.de` eingeben
- IMAP-Port: `993` eingeben
- Kennwort eingeben
- SMTP-Hostname: `smtp.strato.de` eingeben
- SMTP-Port: `465` eingeben
- Kennwort eingeben
- Abschluß der Einrichtung
